# HumaFlo.github.io

## Homepage view counter

The homepage counter uses Hits.sh's hosted SVG counter. It updates each time the
badge loads and does not require an account, credentials, or backend. The counter
is keyed by the public `humaflo.github.io` URL slug in `index.html`.

The count is public and anyone who knows the badge URL can increment it. The browser
requests the image from Hits.sh with referrer sharing disabled; as with any third-party
image request, the provider receives the visitor's IP address. Account for the external
service in the site's privacy notice where required.
